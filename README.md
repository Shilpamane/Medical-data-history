# 🏥 Medical Data History Analysis (SQL Project)

## 📌 Project Overview

The **Medical Data History** project focuses on analyzing patient medical records using **SQL** to extract meaningful insights. This project demonstrates strong skills in **data querying, filtering, updating records, and analytical thinking**, which are essential for Data Analyst roles.

---

## 🎯 Objectives

* Analyze patient medical records using SQL queries
* Retrieve meaningful patient information based on conditions
* Perform data filtering, pattern matching, and updates
* Strengthen SQL querying and data handling skills

---

## 🧰 Tools & Technologies

* **SQL** (MySQL / PostgreSQL / SQLite)
* **Relational Database Concepts**
* **CRUD Operations** (SELECT, UPDATE)

---

## 📂 Dataset Description

* Medical patient dataset
* Includes information such as:

  * Patient ID
  * First Name
  * Last Name
  * Gender
  * Age
  * Weight
  * Allergies
---

## 🔍 Project Tasks & Queries

### 1️⃣ Patient Filtering Queries

* Retrieve patients by gender
* Identify patients without allergies
* Find patients whose names start with specific letters
* Filter patients by weight range

### 2️⃣ Pattern Matching

* Used `LIKE` operator for name-based searches
* Applied conditions using `BETWEEN`, `IS NULL`, and logical operators

### 3️⃣ Data Update Operations

* Updated patient allergy information
* Maintained data integrity while modifying records

---

## 📊 Sample SQL Operations Covered

* `SELECT` with `WHERE` conditions
* `LIKE` for string matching
* `BETWEEN` for range filtering
* `IS NULL` and `NOT NULL`
* `UPDATE` statements
